Relocate TestE2E_DataStarPatches to datastartest

Rollback: git revert HEAD restores the test to its original location.

02Tier 2: Untangle

2

Clean root go.mod: remove datastartest require + replace

Run GOWORK=off GOEXPERIMENT=jsonv2 go mod tidy on root. Since no file in root imports datastartest anymore, the require and replace lines for datastartest are removed automatically. Verify that static remains in the require block (it is a production dependency via script_handler.go).

Verify: GOWORK=off GOEXPERIMENT=jsonv2 go build ./... passes.
GOWORK=off GOEXPERIMENT=jsonv2 go test ./... -count=1 passes.
GOWORK=off GOEXPERIMENT=jsonv2 go vet ./... passes.
grep datastartest go.mod returns nothing.
Rollback: git revert HEAD restores the datastartest require.
3

Sync go.work and verify all modules

Run go work sync to ensure the workspace is consistent with the updated go.mod files. Verify go.work still lists all 3 modules. Run the full workspace test suite to confirm nothing broke.

Verify: go work sync produces no changes.
GOEXPERIMENT=jsonv2 go test ./... ./datastartest/... ./static/... -race -count=1 passes.
GOEXPERIMENT=jsonv2 golangci-lint run ./... ./datastartest/... ./static/... passes.
Rollback: git revert HEAD restores go.work and go.work.sum.

03Tier 3: Infrastructure

4

Update flake.nix vendorHash

Root's go.mod changed (datastartest removed from require). The Nix build will fail with a vendorHash mismatch. Run nix build to get the error, copy the new hash, and update flake.nix.

Verify: nix build .#checks.x86_64-linux.build succeeds.
nix run .#test passes.
Rollback: git revert HEAD restores the old vendorHash.

04Tier 4: Polish

5

Add per-module GOWORK=off CI isolation tests

Add a CI step to .github/workflows/ci.yml that tests each module independently with GOWORK=off. This catches version drift and missing replace directives that workspace mode masks.

Verify: CI YAML is valid. The new steps run GOWORK=off go build and GOWORK=off go test in each module directory.
Rollback: git revert HEAD removes the CI step.
