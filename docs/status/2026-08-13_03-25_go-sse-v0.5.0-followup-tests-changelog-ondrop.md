Two new test files verifying the cross-layer error-family composition:

- `TestWrapStreamError_DoubleWrapComposition` — Triggers a real write failure
  through `sse.Stream.Send` → `wrapStreamError`. Asserts:
  - `errorfamily.Code(err) == datastar.CodeStreamSendFailed` (outermost wins)
  - `errorfamily.Family(err) == Transient`
  - `errors.Is(err, errWriteFailed)` traverses the double-wrap chain
  - `errors.As(err, &*errorfamily.Error)` extracts the classified type

**`datastartest/errors_test.go`** (4 new tests):

- `TestError_ReadEvents_ScanFailed_Transient` — `CodeSSEScanFailed`, Transient,
  retryable, `errors.Is` chain to underlying cause, `errors.As` type extraction
- `TestError_ReadNEvents_ScanFailed_Transient` — Same code/family via ReadNEvents
- `TestError_UnmarshalSignals_Rejection` — `CodeSignalsUnmarshalFailed`,
  Rejection, non-retryable, `errors.Unwrap` preserves cause
- `TestError_AllPaths_AreErrorFamilyType` — Table-driven `errors.As` coverage
  for every error path in the test helpers
