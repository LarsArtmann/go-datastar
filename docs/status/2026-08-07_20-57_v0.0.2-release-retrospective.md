The root cause was that I didn't read the `.golangci.yml` carefully enough before the first fix attempt — it declares `version: "2"` which requires golangci-lint v2, but I initially tried v1. ## e) WHAT WE SHOULD IMPROVE

1. **Read config files before fixing CI.** The `.golangci.yml` said `version: "2"` on line 1. I should have caught that the pre-built v1 binary wouldn't work with a v2 config before the first push.
2. **Set repo topics immediately after `gh repo create`.** It's a one-liner (`gh repo edit --add-topic`) and makes the repo discoverable.
3. **Verify pkg.go.dev renders.** The badge links there but we never confirmed the docs page actually generated. Should check after proxy caching.
4. **CONTRIBUTING.md is embarrassingly skeletal.** It says `go test ./... -race` without `GOEXPERIMENT=jsonv2` or `GOWORK=off`. Anyone following it will fail. This should have been updated before v0.0.1.
5. **Branch protection should be on before a public release.** Without it, any collaborator can force-push to master.
